# Changelog

All notable changes to this package will be documented in this file.

## [0.2.0] - 2026-05-21

### Added

- Destination-first tween overloads such as `MoveToWorld(float3 destination, float time)`.
- Fluent aliases: `To(...)`, `From(...)`, and `Along(...)`.
- Quick Start sample metadata.

### Changed

- Narrowed the intended public API around fluent tween, chase, and sequence builders.
- Hid runtime implementation details from the public surface where possible.
- Updated package metadata for public release.

## [0.1.0]

- Initial Entityween package structure.
